# Portfolio — setup notes

## Deploy it (takes ~5 minutes)
1. Create a new GitHub repo, e.g. `portfolio` or `alishaather.github.io` (the second option gives you the cleanest URL: `alishaather.github.io`).
2. Push both files (`index.html`, `resume.pdf`) to the repo's root — no folders, no build step.
3. Go to the repo's **Settings → Pages** → under "Source" pick the `main` branch, root folder → Save.
4. Wait ~1-2 minutes, then your site is live at the URL GitHub shows you.
